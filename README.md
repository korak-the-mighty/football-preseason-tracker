# Football Pre-Season Tracker

A small, useful web app for finding the next pre-season matches of the football clubs you care about.

Choose clubs from Europe's top five leagues. See their upcoming matches in one chronological list, in your local time. Keep your selection or share it with friends.

## Project status

Club and fixture research phase. The 96-club list is complete; the Premier League pass plus Bundesliga and La Liga baselines are in place; the first build has not started yet.

## Working principle

The interface is the easy part. Trustworthy fixture data is the product.

## Planned first release

- Clubs from the Premier League, Bundesliga, La Liga, Serie A and Ligue 1
- Select and remember favourite clubs
- One chronological list of upcoming pre-season fixtures
- Kickoff times in the visitor's local timezone
- Shareable team selections
- Venue, status and source when available
- Clear last-updated information
- Mobile-first, no account and no backend required for version one

The intended public home is a focused route on Henrik Lehtikangas's website, currently planned as `willworkforkarma.com/preseason`.
